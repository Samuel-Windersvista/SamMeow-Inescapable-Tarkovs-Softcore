# ADR-0002：默认数值以旧包「最终游玩态」为基准

- 状态：已接受（2026-09-26）
- 决策人：Overseer（用户）

## 背景

旧包六组功能中有四组存在「沉浸感增强」覆盖层（True Items Redux / 反重力臂章 / 更大的背包 / Softcore），Softcore 另有《难度：生存》预设覆盖。按 MO2 约定（modlist.txt 顶部 = 最高优先级），叠加后的结果才是实际游玩数值。示例：反重力臂章 = 22 款 / -6 ~ -25kg（覆盖版），而非 5 款 / -20 ~ -100kg（基础版）；Softcore = 生存版（跳蚤 1 级开放、现金换物 5%、弹药堆叠 ×5、保险 70%/80% 等）。

## 决策

新 mod 开箱默认值 = 基础六件套 + 沉浸感增强 + 难度：生存 的叠加结果（最终游玩态）；同时产出「差异表」（基础 vs 沉浸感 vs 生存）写入规格书，便于逐项微调。

## 备选方案

1. 忠实基础 mod 默认值 —— 否决：与实际游玩体验不符。
2. 默认留空、由用户全量配置 —— 否决：开箱不可用。

## 后果

- 正面：开箱即旧包体验；差异可追溯、可微调。
- 负面：默认值来源分散于多个覆盖目录，需差异表作为唯一数值真相。
