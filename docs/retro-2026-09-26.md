# 开发回望：Inescapable-Tarkovs-Softcore v0.1.0（2026-09-26）

> 对象：首个 ship 周期（grill-with-docs → to-spec → to-tickets → 链路实现/双轴审查 → 部署 → 验收反馈修复 R1）。
> 用途：后续 SPT5 移植/整合工作的工作基准。环境改进候选见文末（按严重度）。

## 一、领域经验（每条都来自实际踩坑，均已实证）

1. **运行时真值**：编译引用与反射以 `SPT_Runtime\*.dll` 为准；源码快照存在修饰符/可空性差异（`required`、字段类型），只作语义参考。
2. **读代码不读注释**：「最终游玩态」= 实际执行文件 + 实际 DB。已证伪案例：SURV 容器覆盖是否存在（误判 → 尺寸错 5 处）；ScavCase 注释「更快」实为 ÷0.5 变慢；Crisis 任务条件已被 BSG 从 5.0 数据移除。
3. **5.x 世代陷阱三件套**：
   - 任务 `name` 在 5.0 是本地化键（`<id> name`）→ 按名匹配**静默全失效**（786/786）→ 一律按 **id** 匹配；
   - 实体变体爆炸（安全容器家族 15 员，玩家现役的是变体）→ **按父类枚举 + 映射表 + 未知变体告警**；
   - id 世代更替（`MEDKIT`→`MED_KIT` 重命名、4.x 时代 id 在 5.0 消失、新增大量物品）→ 任何「照抄旧表」必须对照当前 DB **全扫**（失效项 + 新增候选）。
4. **行为归属判定**：先问「这个行为发生在客户端还是服务端」。原版 Sort 从不合并堆叠（0.16 与 0.16.9.5 反编译双证；合并只在拖拽路径，且要求同模板 + 同 FiR + 未满堆）；旧包「排序合并」来自客户端插件 Seion IOF —— 服务端永远补不了客户端交互。
5. **部署期即验证期**：手册价缓存时序（Preload 改写 vs HandbookPriceCache）、DI 单例可注入性、客户端呈现路径——只能上真服务器验证；首启日志 + 进游戏验证优先于离线自信。
6. **方向语义钉死**：`cellsH/cellsV`、tuple 记法、源数据错标（臂章/近战父类对调）→ 数据表 + 锚点断言 + 与源 SHA256/逐字节比对。

## 二、流程经验（agent 工作流）

7. **独立 Spec 轴审查不可省**：抓到三类测试永远抓不到的问题——覆盖层误判（T08 容器尺寸）、locale-key 静默失效（T11 任务匹配）、配方首条命中漂移（3/4 项落到错误配方，靠钉 `recipeId` 修正）。
8. **夹具必须对齐生产形态**：夹具用人类名 vs 生产 locale key → 测试全绿而行为死。计数断言不足以代替**独立源对照**。
9. **worktree 车道并行**：4 路 worktree + 1 条串行链可行；共享文件（`ModuleConfigs` / 模板 / `README`）是冲突面，add/add 冲突按并集解决；`ConfigLoader` 类共享逻辑改动必须做**语义和解**（T07 递归校验 vs T03/T05 字典型叶冲突是实例）。
10. **部署保护**：升级 `copy-if-missing`（config / data 不覆盖玩家编辑）；profile 备份先行（可回滚）；DLL 更新前必须关闭游戏/服务器/启动器（文件锁）。
11. **Windows 编码陷阱**：PowerShell `Get-Content -Raw` + `Set-Content -Encoding utf8` 管道读写 UTF-8 = 灾难（曾乱码并吞掉一条断言）；批量编辑用整文件写入；含中文的 `.ps1` 必须以 **UTF-8 with BOM** 保存。
12. **网络韧性**：git 443 间歇失败 → fail-fast 探测（`-c http.lowSpeedLimit=1000 -c http.lowSpeedTime=20`）优于盲等；积压 51 个提交后一次性推送成功。

## 三、环境改进候选（按严重度）

1. **[高] 数据完整性检查脚本**：把「本 mod 数据表 id 必须存在于 SPT5 DB」固化为可重复命令（如 `tools/check-data-ids.ps1`，DB 路径参数化）。当前是一次性审计，应变为项目内可重复的守卫。
2. **[高] CI / guardrail**：仓库有 build+test 但无 pre-commit hook、无 CI。最小 GitHub Actions（dotnet build + test）即可兜住编码/数据事故进入历史。
3. **[中] 指针补录**：README「参考源」节（已随本文件同批落地）；日志三重位置说明（overwrite 层 / 游戏根 / 实例）。
4. **[中] 审查规则卡片**（供 review 读取）：数据改动必须随带计数/锚点测试；「按 id 不按 name」；数据加载容错约定（磁盘优先、兜底告警）。
5. **[中] 知识库补充（toolkit）**：将本文「领域经验」收编为 spt-kb 条目（SPT5 移植陷阱清单），供全部后续项目复用。
6. **[低] 工具化**：UTF-8 读取小工具（避免控制台 mojibake）；fail-fast push 包装脚本。
